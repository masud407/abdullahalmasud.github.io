# Quantitative Analysis of Doppler Twinkling Artifacts

## Overview

This project investigates ultrasound Doppler twinkling artifacts generated by PMMA markers and kidney stones.

## Motivation

Twinkling artifacts improve ultrasound conspicuity but their physical origin remains incompletely understood.

## Methods

- Doppler signal acquisition
- Spectral analysis
- Time-frequency analysis
- Signal processing

## Key Findings

- Identified unique spectro-temporal signatures
- Quantified artifact stability
- Improved marker characterization
